# 已保存的文件夹比较

不带参数启动 `sidemirror`。主屏幕列出已保存的比较，并提供明确的 **New comparison（新建比较）** 条目。配置是完整的比较会话，而不是连接书签。

## 创建、打开和更新比较

1. 选择 **New comparison** 并按 Enter，或按 `n`。
2. 输入比较名称。
3. 在 **Source settings（源设置）** 中选择 Local 或远程协议，填写对应字段。
4. 独立选择并配置 **Destination settings（目标设置）**。
5. 输入每个端点的文件夹，可选填写以分号分隔的忽略 glob。
6. 按 Enter 或 Ctrl-S **保存并打开** 比较。

Tab/Shift-Tab 或上/下键移动字段。F1 选择名称，F2 选择源，F3 选择目标。两个端点面板各自滚动到当前字段。Space 或左/右键切换类型和单选选项。在类型字段中，`l` 选本地、`r` 选 SFTP、`u` 选 URL 快捷方式、`b` 选连接书签。Ctrl-U 清空文本字段。切换连接类型会清除会话密码和令牌，防止将凭据带到其他协议。保存时本地根目录必须存在；远程设置离线验证，仅在打开时连接。

文本字段会在输入位置显示终端光标；内容过长时会水平滚动，掩码密码和宽 Unicode 字符也适用。

每个端点输入的密码和 S3 秘密访问密钥始终在连接成功后直接保存到操作系统原生凭据存储，重新打开时自动复用。原生存储是强制要求，不提供 F4 关闭选项、仅会话密码模式或文件回退。S3 临时会话令牌和安全令牌仍仅临时使用。原生存储始终编译，即使使用 `--no-default-features` 也不会禁用。

两端均提供原有 termscp 的设置：

| 类型 | 设置 |
| --- | --- |
| Local | 文件夹 |
| SFTP / SCP / FTP / FTPS | 主机或 SSH 别名、端口、用户名、掩码密码、文件夹 |
| S3 | Bucket、区域、端点、AWS 配置名、访问密钥 ID、掩码秘密访问密钥/安全令牌/会话令牌、路径风格寻址、文件夹前缀 |
| GCS | Bucket、端点、服务账户 JSON 文件（留空使用 ADC）、文件夹前缀 |
| Kubernetes | 命名空间、集群 URL、用户名、证书和密钥文件路径、文件夹（`/pod/container/path`，`/` 可列出 Pod） |
| WebDAV | HTTP(S) URI、用户名、掩码密码、文件夹 |
| SMB | 主机、用户名、掩码密码、共享、文件夹；POSIX 还提供端口、工作组和 Auto/SMB1/SMB2/SMB3 协议版本 |
| URL shortcut | 标准 SFTP/SCP/FTP/FTPS 或 HTTP(S) WebDAV URL，可选会话密码 |
| Connection bookmark | 连接名称（也可输入 `bookmark:NAME`），可选会话密码或默认秘密值覆盖 |

仅启用 `smb` 功能的构建提供 SMB。Windows 的 SMB 版本协商由系统管理，POSIX 专有设置会保留但不能编辑。SMB1 不安全，仅应在隔离的旧设备环境中使用。编辑已有 URL 配置时会展开完整的协议设置字段。

两端可独立选择本地或远程文件夹，包括 **远程↔远程**。所有协议的连接书签与显式设置复用相同的原有客户端。文件夹指定已有根目录，不是复制目标；保存不会创建端点目录。

选择已保存的比较并按 Enter 重新打开。在主屏幕按 `e`，或在比较界面按 `s` 编辑设置。保存会**更新同一个配置，并立即使用新的端点和规则重新打开**。重命名会原子更新配置，不会创建副本；不能与另一个已有比较重名。主屏幕的 `d` 在确认后删除配置，绝不删除端点上的文件。

源与目标仅标识两列：文件夹扫描是只读操作；文本比较支持确认后的双向复制。原有的文件传输和连接书签界面仍可通过 `sidemirror transfer` 打开。

在比较界面按 `o` 返回已保存的比较列表。在根列表按 Escape 退出，不会重新打开上一次比较。在配置文件夹内按 Escape 返回根列表。

## 整理已保存的比较配置

在比较主页选择配置并按 `c` 可复制配置。编辑器会填入原有设置并生成唯一名称；按 Enter 保存并打开副本，按 Escape 取消且不保存。会话密码和令牌不会复制。

按 `f` 创建用于整理配置的单层文件夹。按 Enter 打开文件夹，按 Backspace 或 Escape 返回根列表。选择配置并按 `m`，即可列出可用文件夹，包括 **Root (no folder)**（根列表）。当前所属文件夹会被标记并选中。使用上/下键（或 j/k）、Home/End 选择目标，按 Enter 移动，按 Escape 取消。新建和复制的配置保存在当前文件夹内。重命名保留所属文件夹，删除配置不会删除文件夹。选择文件夹并按 `d` 可删除该文件夹；确认时按 `y`，取消时按 `n` 或 Escape。其中的配置会返回根列表，不会删除任何配置或源端、目标端文件。配置名称仍须全局唯一，因此 CLI 的 `--profile NAME` 用法不变。

这些文件夹仅用于整理配置，不会创建、移动或修改源端或目标端的文件。文件夹名称及成员关系与配置一起保存在 `comparisons.json` 中；不包含文件夹的旧文件仍可正常加载。

## CLI 快捷方式

在源码目录中运行：

```sh
cargo run --no-default-features --features keyring
cargo run --no-default-features --features keyring -- compare ./source ./destination
cargo run --no-default-features --features keyring -- compare ./local 'sftp://user@server:22/folder' --save website
cargo run --no-default-features --features keyring -- compare --profile website
```

使用已构建的程序：

```sh
sidemirror compare 'sftp://user@server:22/source' ./local --save download-review
sidemirror compare 'sftp://user@server-a/source' 'ftps://user@server-b/destination' --save server-review
sidemirror compare bookmark:source-server bookmark:destination-server
sidemirror compare ./source ./destination --ignore '.git' --ignore '*.tmp' --differences
```

不提供端点的 `compare` 是主屏幕的等效命令。比较 URL 使用**标准 URL 路径**，不同于原有传输 CLI 以冒号分隔目录的语法。

每个端点独立复用 SSH agent、配置的 SSH 密钥和配置文件、AWS 配置和默认凭据、GCS ADC、kube 配置以及连接书签凭据。SSH 端口留空时使用 SSH 配置；FTP 默认端口为 21。设置中的密码、S3 秘密密钥及令牌均以掩码显示，仅传给对应端点的工作线程客户端，不写入比较配置。访问密钥 ID 和凭据文件路径会保存，但不保存文件内容。密码和 S3 秘密访问密钥会自动从原生凭据存储复用。临时令牌需重新输入，也可使用凭据配置。

密钥环中的密码按完整端点设置区分（包括协议、用户、主机和文件夹），不按比较名称区分。重命名配置后仍可复用；端点设置完全相同的配置可共享同一密钥环条目。设置改变后需要重新输入凭据。新输入的密码优先于已保存的密码，仅在认证成功后替换旧值；密码输入框留空则复用现有认证。密钥环读写失败会明确报告，此功能绝不退回文件存储。需要删除已保存的条目时请使用操作系统凭据管理器。`--wno-keyring` 会被拒绝；构建参数不能禁用原生存储。旧配置即使关闭了记住密码，也会使用强制原生存储。

原生密钥环条目使用易读的连接名称，而不是序列化设置，并附带简短指纹以区分完整端点身份。首次读取旧条目时会将其复制到新名称；迁移过程中 macOS 可能仍显示一次旧名称。原条目会保留。

`--password-prompt` 和 `a` 可使用独立的掩码密码或默认秘密值输入框重新连接；S3 的默认秘密值为秘密访问密钥。显式 GCS/Kubernetes 设置不询问通用密码。使用 `s` 更新凭据文件路径或全部 S3 令牌字段。不要在服务器 URL 中放入凭据或签名查询。如果原生存储不可用或被锁定，请配置或解锁后重试，不提供回退。

**安全限制：**原有 SFTP/SCP 客户端尚未验证 SSH 服务器主机密钥，当前 native-TLS FTPS 客户端也接受无效证书或主机名。在实现验证前只连接可信端点。普通 FTP 不加密。

## 配置存储

配置原子保存在 sidemirror 配置目录的 `comparisons.json` 中。版本 3 存储有类型的 `source`/`destination`、名称、忽略 glob 和可选的 `remember_passwords` 布尔值（旧配置默认为 false）。端点类型包括 `local`、`remote`（URL 快捷方式）、`bookmark` 和 `connection`（经验证且无秘密值的原有连接设置）。密码、秘密访问密钥、安全令牌和会话令牌的值绝不写入此 JSON 文件；主动启用后记住的密码或默认秘密值仅保存在操作系统密钥环中。

版本 1 和 2 会自动加载，不访问文件系统或网络。版本 1 的 `left`/`right` 转换为本地源端点比较；版本 2 的源和目标配置保留。下次成功保存、更新或删除时，所有配置写为版本 3。连接书签仍是独立的数据，不自动转换为比较会话。

忽略 glob 匹配以斜杠分隔的相对路径；匹配目录后不再扫描子项。`.git` 忽略根目录的 `.git`，`*/.git` 还可忽略嵌套目录。隐藏文件默认包含在扫描中。路径匹配区分大小写。

在比较视图选中文件或目录后按 **i**，即可将其相对于根目录的完整路径追加到两侧的忽略规则。目录规则也会排除其所有后代。已保存配置的规则会立即写入；未保存的比较仅保留在内存中，可按 `s` 保存。条目及其后代会立即消失，目录汇总根据现有结果重新计算。其他结果、当前目录和正在进行的扫描保持不变，不触发重新启动、重新列目录或重复验证。后续更新也会经过过滤，因此当前扫描不会将忽略的条目重新显示出来。工作线程可能继续完成按原规则安排的任务；手动按 `r` 刷新或重新打开时，扫描会使用更新后的规则。不修改端点文件。包含 `*`、`?`、`;` 或非 UTF-8 名称的路径无法以此方式作为字面路径添加；操作会显示说明，而不是产生过于宽泛的规则。可按 `s` 手动编辑 glob。

## 结果与安全

比较列上方显示 **Show: All files & folders（全部文件和文件夹）/ Differences only（仅差异）** 切换控件。当前选项以高亮和方括号标识；按 `d` 即时切换，无需重新扫描。它同时过滤两列的文件和文件夹，也适用于嵌套目录和递归视图。仅差异模式隐藏已确认相等的条目；等待、未验证和错误条目仍然显示，避免将未完成的扫描误认为相等。`--differences` 可直接以此模式启动。

两列共享排序、选择和过滤状态。仅一侧存在的目录仍可浏览，另一侧显示占位符；浏览不会创建目录。

状态包括相等、不同、仅左侧（源）、仅右侧（目标）、类型冲突、等待、未验证和错误。大小相同的文件以流式字节比较判定，不使用时间戳。已知大小不同的文件无需下载即可判定不同。远程验证可能从两台服务器传输大量数据。

扫描后目录状态汇总其后代结果。无法访问或取消的子树不会被标记为相等。不跟随符号链接，也不读取特殊文件，配对条目保留为未验证。扫描不是快照，扫描期间发生变化时可能需要刷新。

每个文件夹的列目录操作返回后，条目立即增量显示：先更新源列，再更新目标列；发现另一侧时原地合并配对行。扫描期间可以进入目录。尚未列出的另一侧不会被判定为缺失；条目在清单完成前保持等待状态，随后分批显示字节验证结果。刷新时清除旧行并增量显示新清单。进度信息显示当前列出的目录或验证的文件。单次远程列目录被阻塞时，必须等待服务器返回后才能显示该次结果。

工作线程拥有连接，键盘操作保持响应。取消是协作式的：阻塞的连接、列目录、读取或流结束操作必须先返回。旧任务结果不会覆盖当前会话。

文本比较支持每侧最多 5 MiB、10,000 行的 UTF-8 或 Windows-1252 文件。二进制文件保留文件夹级字节比较结果，但不能打开文本比较。`␍` 表示 CRLF，`[no final newline]` 表示最后一行没有换行符。文本比较中用 `n`/`p` 选择差异块，`F5` 从左向右复制，`F6` 从右向左复制。`F7` / `F8` 分别向右 / 向左复制整个文件。按 `y` 确认，其他键取消。复制立即写入并重新加载比较；Escape 返回并重新扫描文件夹。写入前检查两侧快照，文件已变化时需重新打开。本地原子替换并保留权限；远程写入非原子，失败可能留下部分内容。无法防止写入期间的并发修改。仅支持两侧均存在的普通文本文件，不提供删除、自动同步或任意远程命令执行。SCP 和 Kubernetes 的原有后端可能在内部执行只读的列目录、stat 或读取命令。

按 Enter 打开两侧均存在的文件时，会中断当前文件夹扫描，无需等待完整比较完成；若远程 I/O 正在阻塞，仍需等待该操作返回。从文本比较返回后会重新扫描文件夹。

优先按 UTF-8 解码（保留 BOM），失败后回退到 Windows-1252，并非通用编码检测。纯 ASCII 文件视为 UTF-8。各列显示编码。差异块复制保留目标编码，无法表示字符时拒绝写入；整文件复制保留源字节和编码。解码后的文本可能相同，但文件夹字节比较仍会显示编码差异。

文本比较两列根据文件名自动启用深色语法高亮，支持跨行注释和字符串；未知文件类型回退为纯文本。差异块使用背景色标记，选中块另行突出显示，语法颜色不会替代差异标记。高亮结果在打开或重新加载比较时缓存。
